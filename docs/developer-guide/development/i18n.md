# Internationalization (i18n) Runbook

Kaiku keeps one English source catalog for the web client (`client/src/i18n/en/<area>.ts`) and mirrors keys in the Android `strings.xml`. `cd client && bun run i18n:check` (also run in CI) enforces the rules below.

## Add a string

1. Pick the area file `client/src/i18n/en/<area>.ts` from the first key segment (`common, connection, time, errors, auth, qr, onboarding, home, dm, channels, chat, voice, settings, admin, notifications`). A new area is a new file plus one spread line in `client/src/i18n/en.ts`.
2. Key format `area.screen.purpose` (C15): lower camelCase segments, one whole sentence per key, `{{name}}` placeholders. Never join fragments (`{" "}`), build plurals with `"s"` ternaries or concatenate around `t()`.
3. Use it as `t("area.screen.purpose", { name })`. `t()` takes a literal key or a `MessageKey`; template-literal keys are forbidden because the unused-key check finds keys by their literal text.
4. Run `bun run i18n:sync` to add the key (value `""`) to every `locales/*.json`, then `bun run i18n:check`.
5. Add the component to `I18N_GUARDED_FILES` in `client/eslint.i18n.mjs` once its UI is fully migrated.

## Plurals and dates

Counts use `plural(count, { one, other })` with sibling keys `x.one`/`x.other`; `other` is required, other CLDR categories (`few`, ...) can be added. Dates, times, relative times and list joins go through `client/src/i18n/format.ts`; numbers follow the system region unless the user picked a language, words follow the UI language. Never hardcode `"en-US"`.

## Android strings

- Name = `toAndroidName(webKey)`: `connection.retryNow` becomes `connection_retry_now`. Two web keys that map to one Android name fail the check.
- Placeholders are `%1$s`/`%1$d` (only the key is mirrored, not the syntax). Web plurals `x.one`/`x.other` are one `<plurals name="x">`; read them with `pluralStringResource`.
- ViewModels expose `@StringRes Int` and never English text or server `message` strings.
- Names match `/^[a-z][a-z0-9_]*$/`.

## Add a language

Web:

1. `cd client && bun run i18n:sync -- --add fr` creates `src/i18n/locales/fr.json` with empty values.
2. Add `fr` to `Locale`, `LOCALES` and `LOCALE_NAMES` in `src/i18n/locale.ts`.
3. Translate (empty values fall back to English per key; placeholders must match).
4. Enable the picker with `VITE_FEATURE_LOCALE_SWITCH=true` once the file is complete.

Android:

1. Create `values-fr/strings.xml` and fill it completely (every string and plural of `values/`).
2. Add the language to `locales_config.xml`.
3. Set `MissingTranslation` to `error` in `lint.xml`.

## Turning German on

Checklist (C17):

- [ ] `client/src/i18n/locales/de.json` has no empty values, `bun run i18n:check` is green.
- [ ] Android `values-de/strings.xml` translates every string and plural (a partial folder fails CI, since Android picks it from the system language).
- [ ] `de` is listed in `locales_config.xml` and `MissingTranslation` is `error` in `lint.xml`.
- [ ] Web build sets `VITE_FEATURE_LOCALE_SWITCH=true`.
- [ ] 24 h clock times and `23. Okt.`-style dates still follow the system region with the language left at default.
